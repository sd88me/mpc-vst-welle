Welle 0.3.0: new DISKS page features, plus the +FAV naming keyboard.

**New**
- **RANDOM** on the DISKS page: loads a random disk, then a random performance on it.
- **Disk readout with < > steppers** at the top of the Disks panel, like the performance one; the disk list now has 11 tiles per page, lined up with the performance grid.
- The selected disk and performance tiles stay lit.
- **+FAV opens a drawn naming keyboard** (SHIFT, DEL, SPACE, CANCEL, SAVE; up to 20 characters, shown beside the name field).

Saved projects load as before: the parameter order is unchanged (new parameters are appended).

**Install**
- With the OpenMPC Plugin Manager: install or update Welle; your Wave OS files and sound sets stay in `Content/`.
- By hand: unzip `Welle-0.3.0-VST2-Plugins.zip`, copy the folder into `VST2 Plugins`, put `w2sys.bin` and `wdv.sys` in `Content/roms` and your sound sets in `Content/banks`, restart.

No firmware or sounds are included: you need your own copy of Wave OS 1.700.
